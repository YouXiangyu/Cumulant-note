# TheBrain

TheBrain 是一个计划中的外置大脑项目，目标是提供类似 Obsidian 的个人知识管理体验。项目将围绕本地优先、可组织、可连接、可长期维护的知识系统展开。

## 当前状态

项目处于初始化阶段，尚未选定技术栈，尚未开始功能开发。

## 目标功能

已记录需求：

- 构建一个类似 Obsidian 的外置大脑项目。
- 支持持续维护项目当前状态和未来目标。
- 项目协作时由助手承担项目经理角色。
- 功能开发前先规划，确认后再执行。
- 在环境支持时，使用 subagent 执行已规划好的开发任务。
